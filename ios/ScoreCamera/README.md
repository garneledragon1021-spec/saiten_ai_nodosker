# ScoreCamera

iPhoneのカメラで撮影した答案画像、または写真ライブラリから選んだ答案画像を、端末内だけで採点するSwiftUIアプリです。

## 構成

`カメラ映像または画像取得 → QRコード確認 → Core ML領域検出 → Core ML数字認識 → 合計点表示`

既存の `all.py` で使っている2つのYOLOモデルをCore MLの `.mlpackage` としてアプリに同梱しています。Xcodeのビルド時に `.mlmodelc` へコンパイルされ、iPhone本体だけで推論します。

## 起動手順

1. Xcodeで `ios/ScoreCamera/ScoreCamera.xcodeproj` を開きます。
2. Targetの Signing & Capabilities で自分のTeamを設定します。
3. 実機iPhoneを選択して実行します。
4. 「リアルタイムカメラで採点」「写真を撮って採点」「写真から読み込んで採点」のいずれかをタップします。
5. 指定QRコードを含む答案画像を読み込むと、設問別得点と合計点が表示されます。

## 注意

- カメラ利用は実機iPhoneが必要です。
- リアルタイムカメラでは、カメラ映像上に合計点・設問検出数・数字検出数を重ねて表示します。
- カメラはiOS標準の書類スキャンではなく、通常の写真撮影として読み込みます。
- 写真選択はシミュレータでも画面確認に使えます。
- 画像は端末外へ送信しません。
- モデルを同梱するため、アプリサイズは通常より大きくなります。
- 撮影時は答案全体とQRコードが画面に入り、紙の傾き・影・手ぶれが少ない状態にしてください。
- 採点後に「採点対象として切り出した画像」と「設問検出数 / 数字検出数」を表示します。ここで切り出し範囲がずれている場合は、撮影角度またはQR検出位置が原因です。
